MACHI TALK V1
================
This is a lightweight Android/browser prototype for the live voice translator idea.

Languages:
Tamil, Hindi, English, Telugu, Bengali

What works:
- Language selection and swap
- Microphone speech recognition where the Android browser supports it
- Translation display for a few demo phrases
- Text-to-speech of the displayed translation

Important:
This V1 is a prototype. It does NOT yet connect to a real translation API or provide a true cellular call bridge. The next version can connect speech-to-text, translation, and text-to-speech services for real sentences and then build the call/telephony layer.

How to test:
1. Extract the ZIP.
2. Open index.html in a browser that supports Speech Recognition (Chrome on supported Android devices).
3. Give microphone permission.
4. Select languages and tap START.

For phone-call testing, put the normal call on speaker and use the app to listen/translate. Accuracy and browser support vary by device.
